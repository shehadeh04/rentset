# Design skills

All skills in this directory (except any with their own `SOURCE.md`) are
copied verbatim from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill),
MIT licensed — see `LICENSE` in this folder.

Most of these assume a Next.js + Motion/GSAP + image-generation stack.
RentSet is a Vite SPA with none of that tooling, so treat the *principles*
(typography discipline, color restraint, layout rules, copy audits) as
applicable and the framework-specific code samples (GSAP skeletons,
`next/font`, Motion hooks) as not — don't add those dependencies just to
satisfy a skill's example code.

- `taste-skill/` — general anti-slop frontend rules for landing pages
- `redesign-skill/`, `minimalist-skill/`, `brutalist-skill/`, `soft-skill/` —
  alternate aesthetic directions
- `brandkit/` — brand/design-token generation
- `image-to-code-skill/`, `imagegen-frontend-web/`, `imagegen-frontend-mobile/`,
  `stitch-skill/` — assume an image-generation tool; not usable as-is here
- `gpt-tasteskill/`, `taste-skill-v1/`, `output-skill/` — variants/earlier
  versions of the main taste skill
